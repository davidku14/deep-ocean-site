# 🌊 Deep Ocean Interactive Website

An interactive web experience that explores deep-sea life through animations, visual effects, and modern frontend techniques.

## 🚀 Features

* Animated hero section with canvas-based particle system
* Interactive SVG illustrations of deep-sea creatures
* Smooth scrolling and hover animations
* Responsive layout using modern CSS (Flexbox & Grid)
* Visually immersive UI with gradients, glow effects, and transitions

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)
* Canvas API
* SVG

## 📚 What I Learned

* Creating interactive UI with JavaScript
* Working with Canvas for dynamic animations
* Structuring a multi-section responsive website
* Improving visual design and user experience

## 📌 Future Improvements

* Improve performance and animations
